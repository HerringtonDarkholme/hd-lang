# Guide

These documents introduce hd-lang from complementary perspectives:

- Start with the [Language Overview](OVERVIEW.md) for the language's purpose,
  priorities, and core conceptual model.
- Continue with the [Language Tour](LANGUAGE_TOUR.md) for a guided introduction
  to writing the language.
- Read [Use Scenarios](USE_SCENARIOS.md) for the product needs and workflows
  that shape the design.

For normative syntax and semantics, use the
[formal specification](../spec/README.md). Deferred and exploratory work is
collected under [Future Work](../future-work/README.md).
