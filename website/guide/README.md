# Guide

These documents introduce hd-lang from complementary perspectives:

- Take the [tour](../tour/01-hello.md): one claim per page, with a program
  you run and change in the browser.
- Keep [Learn hd-lang in 10 Minutes](LEARN_IN_10_MINUTES.md) at hand: the
  syntax on one page, with examples that parse.
- Read the [Language Overview](OVERVIEW.md) for the language's purpose,
  priorities, and core conceptual model.
- For everyday jobs — JSON config, doc tests, timeouts, files, log
  scanning, wiring a program in `main`, and packages — read
  [Working With Data](WORKING_WITH_DATA.md).
- For the commands day to day, read [The `hd` Command](COMMANDS.md).
- Read [Use Scenarios](../../docs/use-scenarios.md) for the product needs and workflows
  that shape the design.

For normative syntax and semantics, use the
[formal specification](../../spec/README.md). Deferred and exploratory work is
collected under [Future Work](../../docs/future-work/README.md).
