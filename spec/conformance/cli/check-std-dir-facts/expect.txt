# A file in a directory named `std` is a single-file program like any
# other (#1714): it uses the standard library, which is not its directory,
# so a decorator's facts check against std's `Facts`.
run: hd check lib/std/twice.hd

# It is no part of std, so a runtime module is out of its reach.
