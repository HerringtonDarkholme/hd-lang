| 2026-10-09 | Map iteration while the map changes | The spec does not say whether entries added during an iteration are yielded. | 2026-10-10 | Native syscall cancellation (`cli.limit.time`, M21) | Epochs interrupt Wasm instructions; reactor and network waits use the absolute wall deadline. Unix and Windows Process/filesystem pipe I/O use nonblocking polling without pending I/O or detached mutation workers. A single blocked kernel filesystem call, remote SMB pipe open, blocking output write, or entropy syscall remains an OS limitation. Windows mode changes can require extra attribute rights; refusals remain OS errors, never blocking fallbacks. | Windows source and cross-target checks do not replace native Windows execution; platform-specific pipe tests require a Windows runner |
| 2026-10-10 | Darwin descriptor exhaustion (`cli.limit.time`, M21) | When every descriptor below 1024 is occupied, safe select or low-descriptor duplication cannot detect an empty FIFO writer disconnect. Poll fallback may return the wall timeout instead of empty EOF; data remains readable. Ordinary descriptor cases use select and pass native tests. | Owner accepted documenting this rare edge; no unsafe dynamic-select wrapper |

| 2026-10-11 | `std-ops.default.derive.member-bound.declared` with `annot.omit.default` | The compiler exempts declared-default members only for derivations of the `Default` trait (`OptIn::fills_declared`, keyed to Default). | 2026-10-11 | fact re-entrancy | The spec does not say what a fact that reads itself does. It recurses until `stack-exhausted`. A second read after a failed evaluation cannot happen, since the panic poisons the instance. | Recurses (#285a) |
| 2026-10-11 | `data.shared.per-variant` with `data.enum.generic` | The rules say shared data belongs to the variant and is evaluated once, and name no instantiations. A shared parameter whose type names a generic parameter (`items: List[T]`) has no one type, so it is still `unsupported` at Body. The fixture `runtime/valid/shared-enum-data-computed-once.hd` now passes Body and fails at Collect: it has no `tests:` block and its entry is `fn main() -> i32`, but `i32` does not implement `Termination` (`module.entry.termination` lists `void`, `ExitCode`, `Result`). The generic shared data itself runs and gives 16. | Per declaration (#285d) |
