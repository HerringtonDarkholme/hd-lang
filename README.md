# hd-lang

A statically typed, Python-indented, WebAssembly-targeting language for human-reviewed AI-generated code, with explicit dependency requirements, one-shot suspension, typed metadata derivation, and runtime support for sandboxing, replay, and observability.

Start with the [newcomer guide](guide/README.md) and
[Language Overview](guide/OVERVIEW.md), continue with the
[Language Tour](guide/LANGUAGE_TOUR.md), then use the
[formal specification](spec/README.md) for normative syntax and semantics.
[Use Scenarios](guide/USE_SCENARIOS.md) records the product requirements the design
is intended to satisfy. Forward-looking material is grouped under
[Future Work](future-work/README.md), including the broader
[Runtime and Library Design](future-work/RUNTIME_AND_LIBRARY.md) and the single
[Open Issues](future-work/OPEN_ISSUES.md) backlog.
